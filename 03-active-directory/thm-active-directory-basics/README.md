# TryHackMe: Active Directory Basics

Room that introduces the basic concepts and functionality of Active Directory. AD is the heart of identity and access management in most companies, so I wanted to understand its architecture, its authentication protocols and how it works overall.

It is useful to secure infrastructures against modern attacks like ransomware and lateral movement, to spot misconfigurations that attackers often exploit, and to apply the principle of least privilege properly.

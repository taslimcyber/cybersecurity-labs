# TryHackMe: Linux Competency (badge)

In this module I connected remotely to a Linux VM through SSH: secure handshake, authentication and encrypted session.

What I practiced: navigating the directory tree (cd, pwd, ls), creating and removing directories and files (mkdir, rmdir, touch, rm), handling files (cp, mv, cat, nano), permissions and ownership (chmod, chown), and managing processes and the system (ps, top, df, whoami).

Linux terminal skills are needed for system administration, forensics and SOC work.

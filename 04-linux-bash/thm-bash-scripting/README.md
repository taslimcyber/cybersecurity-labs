# TryHackMe: Bash Scripting

I finished the Bash Scripting module to consolidate my basics in automation under Linux. The goal was to stop typing the same commands in a loop and to write clean scripts that can be reused.

Logic and automation: variables, conditions (if/else) and loops (for/while) to process data.

Quick data analysis: grep, awk and sed used together to parse log files and pull out the important indicators.

Custom tools: interactive scripts that take command line arguments, to automate system administration and reconnaissance tasks.
